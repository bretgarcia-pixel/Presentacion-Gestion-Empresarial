Idea central

Cuando se venden diferentes productos, cada línea puede tener un precio, costo variable y margen distinto. Por ello se utiliza una participación ponderada.

Claves para recordar

  • Calcular el margen de cada producto.
  • Multiplicar cada margen por su porcentaje de participación.
  • Sumar los resultados para obtener el margen ponderado y usarlo en el cálculo.
04 · PRODUCTOS

El caso de varias líneas

Cuando una empresa vende varios productos, el cálculo considera la participación de cada línea y su margen de contribución.

Ejemplo de mezcla de productos

ProductoPrecioCosto variableMargenParticipación
Producto AL 100L 60L 4050%
Producto BL 150L 90L 6030%
Producto CL 200L 120L 8020%
Margen ponderado = Σ (Margen unitario × Participación)

Se pondera el margen de cada producto según su participación en las ventas. Así se obtiene una referencia para la mezcla completa de productos.

Importante: la mezcla de productos debe mantenerse aproximadamente en las proporciones usadas en el cálculo para que el resultado sea representativo.

PROFUNDIZACIÓN

Cuando existen varias líneas

Lectura del concepto

Cuando una empresa comercializa diferentes productos, el análisis debe considerar la combinación de ventas de cada línea. La mezcla de productos influye en el margen de contribución global y, por tanto, en el equilibrio.

Aplicación empresarial

Por ello, el análisis de varias líneas requiere observar tanto el comportamiento de cada producto como su participación dentro del conjunto de ventas.

Preguntas para discutir

¿Qué variable tendría mayor impacto en el equilibrio? ¿Cómo cambiaría la interpretación si se modifican simultáneamente el precio y los costos?
