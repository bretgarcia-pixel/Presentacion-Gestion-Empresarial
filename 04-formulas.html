Idea central

Las fórmulas organizan los datos y permiten pasar de una descripción de los costos a un cálculo cuantitativo del equilibrio.

Claves para recordar

  • Costo total: suma de costos fijos y variables.
  • Margen de contribución: ventas menos costos variables.
  • Punto de equilibrio en unidades: costos fijos divididos entre margen unitario.
04 · FÓRMULAS

Fórmulas principales

Costo total

CT = CF + CV

Suma los costos que permanecen constantes y los que cambian con la producción.

Margen de contribución

MC = Ventas − CV

Muestra cuánto queda de las ventas después de cubrir los costos variables.

Utilidad o pérdida

U = MC − CF

Si el resultado es positivo hay utilidad; si es negativo hay pérdida; si es cero hay equilibrio.

Punto de equilibrio

PE = CF ÷ (PVU − CVU)

El paréntesis representa el margen de contribución por unidad.

Ejemplo paso a paso

En el punto de equilibrio: ventas L 10,000 y costos variables L 5,000.

MC = 10,000 − 5,000 = 5,000
U = 5,000 − 5,000 = 0

Por eso, 5,000 unidades representan el punto de equilibrio.

Otra forma de verlo

Precio unitario = L 10,000 ÷ 5,000 = L 2. Costo variable unitario = L 5,000 ÷ 5,000 = L 1.

PE = 5,000 ÷ (2 − 1) = 5,000 unidades

Qué representa cada variable

Lectura del concepto

La fórmula PE = Costos Fijos / (Precio de Venta Unitario − Costo Variable Unitario) reúne las variables esenciales del modelo. El denominador representa el margen de contribución por unidad.

Aplicación empresarial

Leer la fórmula de esta manera ayuda a comprender que el equilibrio no depende únicamente del volumen de ventas: también cambia cuando se modifica la estructura de costos o el precio.

Preguntas para discutir

¿Qué variable tendría mayor impacto en el equilibrio? ¿Cómo cambiaría la interpretación si se modifican simultáneamente el precio y los costos?
