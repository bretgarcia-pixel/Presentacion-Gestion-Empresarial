PRESENTACIÓN INTERACTIVA — PUNTO DE EQUILIBRIO
================================================

Esta versión está diseñada como presentación web académica de Gestión Empresarial.

CARACTERÍSTICAS
- Tipografía principal: Times New Roman.
- Paleta verde militar, blanco y dorado.
- Menú lateral expandible al pasar el cursor.
- Navegación por teclado: ← → y Home.
- Sonido interactivo activable/desactivable.
- Águila como elemento principal y fondo águila/león.
- Diseño responsive para computadora, laptop y tablet.
- Fórmulas grandes y visibles.
- Tablas de referencia.
- Gráficos y zonas de equilibrio.
- Simulador dinámico del punto de equilibrio.
- Mini-juego de preguntas.
- Espacios visuales preparados para futuras imágenes temáticas.

USO
1. Descomprimir el ZIP.
2. Abrir index.html en un navegador moderno.
3. No requiere servidor ni conexión a internet.
4. Para añadir una imagen temática, puede asignarse a un elemento con data-image="ruta/imagen.jpg".

NAVEGACIÓN
- Menú lateral: pasar el cursor por el borde izquierdo.
- ← / →: cambiar de sección.
- Home: regresar al inicio.
- Botón de sonido: activar/desactivar efectos.

NOTA
Los sonidos se generan con Web Audio API y se activan después de una interacción del usuario para cumplir las restricciones de reproducción automática de los navegadores.
